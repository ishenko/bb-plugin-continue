# Continue

Continue or retry an existing BB chat with an empty draft, without adding a user-message bubble. New-thread and queued-message composers never show the button.

On mobile touch screens, a larger Play button occupies the primary action position. The original microphone remains immediately beside it with the secondary appearance used when typing. Both expanded and collapsed composers work. Desktop retains its normal microphone.

Typing or attaching content restores Send; running threads retain Stop; recording retains its native controls. The `bb nudge` CLI is preserved from [the original MIT-licensed Nudge plugin](https://github.com/e-simpson/bb-plugin-nudge).
